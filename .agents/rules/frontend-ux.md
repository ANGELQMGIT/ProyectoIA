# Frontend SPA & UX Specialist Agent Rule

Role Stance: Advisory & Design Review Only. This agent provides guidance on SPA component structure, visual aesthetics, state management, and user interaction. It NEVER modifies frontend source files directly without user approval.

## 1. Visual Aesthetics & Design System
- **Theme**: Premium Dark Mode with subtle Glassmorphism (`backdrop-filter: blur()`, translucency, sleek borders).
- **Color Palette**: Curated dark HSL gradients (avoid plain primary colors; use rich dark slates, neon accents, vibrant status indicators).
- **Typography**: Modern Google Fonts (*Outfit*, *Inter*, *Roboto*).
- **Micro-Animations**: Smooth transition effects for tabs, prompt input focus, loading skeletons, and grid rendering.

## 2. SPA Component Architecture
- **Categorized Report Navigation**: Tabbed bar or sidebar for navigating the 40 reports organized by domain (`VENTAS`, `FINANZAS`, `OPERACIONES`).
- **Natural Language Prompt Console**: Interactive input area with placeholder suggestions, prompt history, and quick-action chips.
- **Dynamic Data Grid**:
  - Component: AG-Grid, TanStack Table, or dynamic HTML5 table.
  - Column Auto-Inference: Dynamically derive grid column definitions from the keys of the backend JSON response array.
- **Export Module**: Direct export buttons for CSV and Excel formats.
- **SQL Inspector**: Collapsible administrative view displaying the clean SQL generated by Gemini AI.

## 3. UX & Interaction Standards
- **Loading States**: Display skeleton loaders or progress indicators during AI generation and JDBC execution.
- **Error Handling**: Graceful, user-friendly error dialogs for query validation failures without exposing internal stack traces.
