# Frontend SPA & UX Specialist Agent Rule

Role Stance: Advisory & Design Review Only. This agent provides guidance on SPA component structure, visual aesthetics, state management, and user interaction. It NEVER modifies frontend source files directly without user approval.

## 1. Visual Aesthetics & Design System
- **Theme**: Premium Dark Mode with subtle Glassmorphism (`backdrop-filter: blur()`, translucency, sleek borders).
- **Color Palette**: Curated dark HSL gradients (avoid plain primary colors; use rich dark slates, neon accents, vibrant status indicators).
- **Typography**: **Plus Jakarta Sans** (UI text, weights 400/500/600/700) + **JetBrains Mono** (SQL/code/numeric contexts). Loaded via Google Fonts in `index.html`.
- **Micro-Animations**: Smooth transition effects for tabs, prompt input focus, loading skeletons, and grid rendering.

## 2. SPA Component Architecture
- **Categorized Report Navigation**: Tabbed bar or sidebar for navigating the 40 reports organized by domain (`VENTAS`, `FINANZAS`, `OPERACIONES`).
- **Natural Language Prompt Console**: Interactive input area with placeholder suggestions, prompt history, and quick-action chips.
- **Dynamic Data Grid**:
  - Component: Native HTML `<table>` driven by React state (AG-Grid removed from dependencies).
  - Column Auto-Inference: Column headers derived directly from `result.columnas[]` array returned by the backend; no hardcoded column definitions.
  - Live Filter: Client-side search input filters `result.filas[]` rows in real time without re-querying the backend.
- **Export Module**: CSV export via native Blob + `URL.createObjectURL` (no third-party library required).
- **SQL Inspector**: Collapsible administrative view displaying the clean SQL generated by Gemini AI.

## 3. UX & Interaction Standards
- **Loading States**: Spinner on the execute button + animated status text during `POST /api/v1/reportes/ejecutar` (AI generation + JDBC execution).
- **Error Handling**: Graceful, user-friendly error banners for query validation failures. Show `error.code`, `error.status`, and `error.traceId` when available; never expose stack traces.
- **Toast Notifications**: Animated slide-in/out toast (auto-dismiss after 2.6s) for all user actions: execute, copy SQL, and export CSV.
- **Execution Metrics**: Display `tiempoEjecucionMs` and the submitted prompt text inline in the results card header after every successful execution.
- **Copy SQL**: Clipboard API button on the SQL Inspector with visual feedback state ("¡Copiado!") that resets after 2s.
- **Sidebar Responsive**: Fixed 288px sidebar on desktop; on mobile, collapses and re-opens via hamburger button with backdrop overlay and CSS slide-in transition.
- **Quick-Prompt Chips**: Clickable suggestion chips below the prompt textarea. Populate the textarea on click. Use `report.sugerencias[]` when available; fall back to static defaults.
- **DB Status Indicator**: Animated pulsing dot in the sidebar footer signaling Oracle connection state.
