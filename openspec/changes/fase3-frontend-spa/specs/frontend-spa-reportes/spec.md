# Spec Delta

## Purpose
Provides the user-facing web application for the dynamic reporting engine, featuring a modern UI to capture prompts, display generated AI SQL, and render dynamic data grids.

## ADDED Requirements

### Requirement: Present a Premium Interactive UI
The system SHALL provide a web application utilizing a premium aesthetic, specifically Glassmorphism and Dark Mode, using modern typography (Google Fonts).

#### Scenario: User opens the application
- **WHEN** a user navigates to the application URL
- **THEN** the system displays a modern, dark-themed dashboard with glassmorphism elements.

### Requirement: Capture User Prompts and Base Queries
The system SHALL allow users to view available base queries from the catalog and input a natural language prompt to generate a specific report.

#### Scenario: User requests a report
- **WHEN** the user selects a base query and types "Show me the top 5 sales in the last month" and submits
- **THEN** the frontend sends a request to the backend execution endpoint.

### Requirement: Render Dynamic Data Grids
The system SHALL dynamically render a data grid (e.g., AG-Grid or TanStack Table) based on the `ResultSetMetaData` returned from the backend execution, adapting columns and rows seamlessly.

#### Scenario: Grid updates with new data shape
- **WHEN** the backend returns a successful response with dynamic columns (e.g., `["CLIENTE", "TOTAL_VENTAS"]`) and rows
- **THEN** the grid instantly creates the corresponding columns and populates the data.

### Requirement: Allow Data Export
The system SHALL provide functionality to export the currently displayed report data to CSV and Excel formats.

#### Scenario: User exports data
- **WHEN** the user clicks the "Export to CSV" button
- **THEN** the browser downloads a CSV file containing the data currently visible in the data grid.

### Requirement: SQL Inspector Tool
The system SHALL provide a SQL Inspector component that reveals the final SQL query generated by the AI and validated by the backend.

#### Scenario: User inspects the query
- **WHEN** the user clicks the "View SQL" toggle or button after generating a report
- **THEN** the system displays the exact SQL string that was executed against the database.
